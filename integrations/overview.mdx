sidebarTitle: "Overview"
description: "Connect Atlasent to GitHub Actions, MCP-compatible AI agents, LangChain, LlamaIndex, Slack, and your SIEM — all from one organization."
---

Atlasent integrates directly into the places where your agents and engineers act. Every integration calls the same `/v1/evaluate` API under the hood, so a single policy bundle governs deployments, agent tool calls, query engines, and human escalations without any duplication. You can run any combination of integrations from one Atlasent organization, with per-API-key scoping to limit what each surface can do.
