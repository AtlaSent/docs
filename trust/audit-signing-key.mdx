AtlaSent signs every audit-chain entry with an **Ed25519** key. The
**public** half is published here so you can verify an exported audit
chain or proof bundle **offline, against a key you obtained from this
trust center — not from the bundle itself.** That independence is the
whole point: a bundle that ships its own key proves nothing; a bundle
whose signatures verify under the key on this page was signed by AtlaSent.

<Note>
  This is the **audit-entry** signing key. It is **not** the
  export-bundle key and not an API key. Pin the value on this page
  out-of-band (this page, a signed email, or your contract appendix) and
  verify against your pinned copy.
</Note>

## Verify with it

**Proof bundle** (`GET /v1/proofs/export` → `bundle.json`) — `--pubkey`
pins this key and **ignores** the bundle's own key registry:

```bash
npx @atlasent/verify bundle.json --pubkey @atlasent-audit-key.pem
# key source: out-of-band pinned key
# verified N/N proofs (0 invalid)
```

`--pubkey` also accepts the raw-base64 value directly, and the
`ATLASENT_PUBLIC_KEY_PEM` environment variable is honored as an
alternative.

**Audit chain** (`atlasent-audit-verify` Go CLI) — supply the same PEM and
require signatures, so an unloaded or wrong key is a failure rather than a
silent skip:

```bash
atlasent-audit-verify --chain chain-export.ndjson --keys atlasent-audit-key.pem --require-signatures
```

## Rotation policy

When the key rotates, the new `key_version` is added to this page and
the old one is **kept published indefinitely** — every audit entry
records the `key_version` it was signed under, so historical exports
stay verifiable forever under their original key. A retired key is no
longer used for new signatures but remains valid for verification. A key
is marked **revoked** only on confirmed compromise; revocation
intentionally breaks verification of entries signed under it.

**Publication gate (added 2026-09-12):** a public key is added to this page
only after it has been shown to verify a current production audit entry
offline. A key that has not passed that check is not published, whatever
the runtime reports as its configured value.
