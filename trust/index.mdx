Every section cross-links to canonical evidence — compliance framework mappings, security architecture detail, legal documents, and sub-processor disclosures — so any question is one navigation step from its answer.

Any inconsistency between this portal and the DPA is resolved in favor of the DPA.
</Note>

## What Atlasent is

Atlasent is execution-time authorization infrastructure. It sits in the execution path of high-impact automated actions — AI agents, CI/CD pipelines, and regulated workflows — and answers one question before any consequential action runs: is this actor authorized to take this action right now, against this target, in this context? Customer data is logically segregated by `organization_id` at the database row-level security layer. No cross-tenant access path exists at any layer of the stack.

## Quick links for enterprise buyers

The following artifacts are the ones enterprise procurement teams request most often. You can request all of them from [security@atlasent.io](mailto:security@atlasent.io) or [compliance@atlasent.io](mailto:compliance@atlasent.io).

<Accordion title="Security questionnaire responses (CAIQ v4)">
  Atlasent maintains a pre-filled CAIQ v4 (Consensus Assessment Initiative Questionnaire) that maps each question to the relevant control in the Atlasent security architecture. Request the latest version from [security@atlasent.io](mailto:security@atlasent.io). The pre-fill is updated quarterly.
</Accordion>

<Accordion title="Vendor Qualification Package (VQP)">
  The VQP is a structured document for regulated-industry customers that maps Atlasent's controls to GxP framework requirements (21 CFR Part 11, EU Annex 11, ICH E6 GCP). It contains ten sections covering vendor profile, system description, control mapping, and contractual schedules. Request a copy from [compliance@atlasent.io](mailto:compliance@atlasent.io).
</Accordion>

<Accordion title="Data Processing Agreement (DPA)">
  Atlasent's standard DPA incorporates EU Standard Contractual Clauses (Modules 2 and 3) and the UK International Data Transfer Addendum. Request the current template from [privacy@atlasent.io](mailto:privacy@atlasent.io). Turnaround is 2 business days.
</Accordion>

<Accordion title="Responsible disclosure and penetration testing">
  Report security vulnerabilities to [security@atlasent.io](mailto:security@atlasent.io) with the subject line `[Security]`. Atlasent acknowledges all reports within 2 business days and provides an initial triage assessment within 5 business days. The most recent third-party penetration test summary is available under NDA on request.
</Accordion>

## How Atlasent keeps this portal honest

- The compliance lead reviews every page in this portal on the first of every month.
- Compliance claims on this portal must match the canonical claims table in [Compliance Overview](/compliance/overview), which is CI-gated against product copy.
- Any change to the security posture requires a parallel update here before it goes live and a corresponding update to DPA Annex II.
- If you find a discrepancy between this portal and any other Atlasent document, email [compliance@atlasent.io](mailto:compliance@atlasent.io) and the other copy will be corrected.
