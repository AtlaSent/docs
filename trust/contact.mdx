## Who to email for what

| Topic | Email |
|---|---|
| Security vulnerability report | `security@atlasent.io` |
| Privacy / data subject request | `privacy@atlasent.io` |
| Compliance / regulated-data questions | `compliance@atlasent.io` |
| Sub-processor questions | `subprocessors@atlasent.io` |
| Legal / contracts / DPA / MSA | `legal@atlasent.io` |
| Procurement / vendor onboarding | `compliance@atlasent.io` |
| Product support / sign-in help | `support@atlasent.io` |
| Abuse / AUP report | `abuse@atlasent.io` |
| General / sales | `hello@atlasent.io` |

## Safe information to include

For support or access problems, include your company name, work email, issue category, a non-sensitive description, and a request/reference ID if one is safe to share.

<Warning>
Do not send passwords, API keys, signing material, recovery codes, regulated data, customer production payloads, or other secrets through a public contact channel.
</Warning>
