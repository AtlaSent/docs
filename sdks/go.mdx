<Warning>
  **The Go SDK is in preview and not yet published.** The Go module has no tagged,
  installable release yet, so no supported `go get` command exists. Earlier versions of this page pointed at a repository
  that no longer exists; that command does not work.
</Warning>

## What to use today

- **The REST API.** Any Go HTTP client can call AtlaSent directly. See the
  [API reference](/api-reference/introduction) for evaluate and
  permit verification.
- **The [TypeScript SDK](/sdks/typescript)** (`@atlasent/sdk`) or the
  **[Python SDK](/sdks/python)** (`atlasent`), if your service can use either.

Whichever you choose, keep the same execution boundary: evaluate the
action, execute **only** after the returned [Permit](/concepts/permit)
verifies, and treat any error, timeout, or non-`allow` decision as a stop.
See [Runtime flow](/concepts/runtime-flow) for the full lifecycle and the
fail-closed matrix.

This page will carry install instructions and examples once the Go
module has a tagged release.
