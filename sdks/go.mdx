The Atlasent Go SDK (`github.com/atlasent-systems-inc/atlasent-sdk-go`) requires Go 1.21 or later. Every SDK method accepts a `context.Context`, which means you can propagate deadlines, cancellation signals, and OpenTelemetry trace spans without any extra plumbing.

<Note>
  The Go SDK is currently in **Beta**. The authorization contract is stable and safe to use in production, but minor changes to the request and response shapes may occur before the GA release. A 3-month deprecation notice will accompany any breaking change.
</Note>

## Installation

```bash
go get github.com/atlasent-systems-inc/atlasent-sdk-go
```

## Client setup

Create a client by passing your API key. The client is safe for concurrent use and should be shared across goroutines rather than created per-request.

```go
package main

import (
    "os"
    atlasent "github.com/atlasent-systems-inc/atlasent-sdk-go"
)

func main() {
    client := atlasent.NewClient(os.Getenv("ATLASENT_API_KEY"))
}
```

## WithGate() — fail-closed gate

`WithGate()` is the canonical execution-boundary primitive in the Go SDK. It evaluates the request, verifies the resulting permit, and invokes your function only if both steps succeed. On deny, hold, escalate, or transport error, the function is never called.

```go
err := client.WithGate(ctx, atlasent.Request{
    Actor:  atlasent.Actor{ID: "user_123", Role: "engineer"},
    Action: atlasent.Action{Type: "production.deploy"},
    Target: atlasent.Target{ID: "my-service", Environment: "production"},
    Context: map[string]interface{}{
        "git_sha": os.Getenv("GITHUB_SHA"),
    },
}, func(permit *atlasent.Permit) error {
    return deploy(ctx)
})
if err != nil {
    log.Fatal("Deploy blocked:", err)
}
```

<Note>
  `WithGate()` is the Go equivalent of `protect()` in the TypeScript and Python SDKs. A future release will add `Protect` and `WithPermit` aliases to complete cross-SDK naming parity. The wire contract and authorization semantics are identical today.
</Note>

## Error model

Use `errors.Is()` to branch on typed sentinel errors. `WithGate()` wraps the underlying error, so `errors.Is()` traverses the chain correctly.

```go
err := client.WithGate(ctx, req, fn)

switch {
case errors.Is(err, atlasent.ErrDenied):
    log.Fatal("Policy denied / verify-fail:", err)
case errors.Is(err, atlasent.ErrRateLimit):
    time.Sleep(atlasent.RetryAfter(err))
    // retry
case errors.Is(err, atlasent.ErrTransient):
    log.Fatal("Fail-closed: authorization unavailable")
case err != nil:
    log.Fatal("Unexpected error:", err)
}
```

<Warning>
  When you receive `atlasent.ErrTransient`, always treat it as a denial. Never fall back to permitting the action if the authorization service is unreachable — that defeats the fail-closed guarantee.
</Warning>

## Four-value decision with Evaluate()

`WithGate()` collapses `deny`, `hold`, and `escalate` into `atlasent.ErrDenied`. If you need to inspect the specific outcome — for example, to route a `hold` to an approval queue — use the raw `Evaluate()` primitive.

```go
result, err := client.Evaluate(ctx, atlasent.Request{
    Actor:  atlasent.Actor{ID: "user_123", Role: "engineer"},
    Action: atlasent.Action{Type: "production.deploy"},
    Target: atlasent.Target{ID: "my-service", Environment: "production"},
    Context: map[string]interface{}{},
})
if err != nil {
    log.Fatal(err)
}

switch result.Decision {
case atlasent.DecisionAllow:
    fmt.Println("Permit:", result.Permit.Token)
case atlasent.DecisionDeny:
    fmt.Println("Denied:", result.DenyCode)
case atlasent.DecisionHold:
    fmt.Println("On hold")
case atlasent.DecisionEscalate:
    fmt.Println("Needs approval")
}
```

<Warning>
  `Evaluate()` does not verify the permit for you. If the decision is `DecisionAllow`, you must call `VerifyPermit()` before executing the action. Skipping verification is audit-weak and bypassable — use `WithGate()` whenever possible.
</Warning>
