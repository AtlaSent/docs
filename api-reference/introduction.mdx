The Atlasent API is a versioned REST API over HTTPS. Every request and response body is JSON, every endpoint lives under `/v1/`, and every request must carry an `Authorization: Bearer` header. If you prefer to integrate through a typed client rather than raw HTTP, the [TypeScript](/sdks/typescript), [Python](/sdks/python), and [Go](/sdks/go) SDKs wrap this API and handle authentication, retries, and error typing for you.

## Base URL

```
https://api.atlasent.io
```

All endpoints in this reference are relative to this base URL. For example, `POST /v1/evaluate` is the full URL `https://api.atlasent.io/v1/evaluate`.

## Endpoints overview

| Endpoint | Method | Description |
|---|---|---|
| `/v1/evaluate` | POST | Evaluate whether an action is permitted |
| `/v1/verify-permit` | POST | Consume a permit before execution |
| `/v1/audit/events` | GET | List audit log entries |
| `/v1/audit/exports` | POST | Generate a signed audit bundle |
| `/v1/policies` | GET, POST | Manage policy bundles |
| `/v1/escalations` | GET, POST | Manage approval requests |
| `/v1/webhooks` | GET, POST | Manage webhook subscriptions |
| `/v1/status` | GET | Health check |

## Authentication

Every request must include your API key as a Bearer token in the `Authorization` header:

```bash
curl https://api.atlasent.io/v1/evaluate \
  -H "Authorization: Bearer ak_live_..." \
  -H "Content-Type: application/json" \
  -d '{ ... }'
```

See [Authentication](/api-reference/authentication) for full details on API key scopes and rotation.

## Quick reference

The two endpoints you call most frequently are `POST /v1/evaluate` and `POST /v1/verify-permit`. The examples below show the minimal viable request for each.

<CodeGroup>
```bash POST /v1/evaluate
curl -X POST https://api.atlasent.io/v1/evaluate \
  -H "Authorization: Bearer ak_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "actor": { "id": "user_123", "role": "engineer" },
    "action": { "type": "production.deploy" },
    "target": { "id": "my-service", "environment": "production" },
    "context": { "git_sha": "a1b2c3d" }
  }'
```
```bash POST /v1/verify-permit
curl -X POST https://api.atlasent.io/v1/verify-permit \
  -H "Authorization: Bearer ak_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "permit_token": "tok_eyJ..."
  }'
```
</CodeGroup>
