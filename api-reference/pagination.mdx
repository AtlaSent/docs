List endpoints (`/v1/audit`, `/v1/permits`, `/v1/approvals`, `/v1/policies`) are paginated with opaque cursors. Cursors are stable — inserting new rows does not shift or duplicate existing pages.

## Request

```http
GET /v1/audit?limit=100&cursor=eyJvZmZzZXQiOjMwMH0
```

| Param | Default | Max | Notes |
|---|---|---|---|
| `limit`  | 50 | 500 | Page size. |
| `cursor` | —  | —   | Opaque. From `next_cursor` of the previous response. |

## Response

```json
{
  "data": [ /* ...items */ ],
  "next_cursor": "eyJvZmZzZXQiOjQwMH0",
  "has_more": true
}
```

When `has_more` is `false`, there is no next cursor and iteration is complete.

## SDK iteration

<CodeGroup>

```typescript TypeScript
for await (const entry of client.audit.list({ from, to })) {
  process(entry);
}
```

```python Python
for entry in client.audit.list(from_=start, to=end):
    process(entry)
```

</CodeGroup>

SDKs handle cursor advancement and stop automatically on `has_more == false`.
